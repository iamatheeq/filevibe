# Profile Craft

GitHub profile README generator with Apple-style UI, dark/light/system themes, and installable PWA.

**Developer:** [Atheeq Urrahman](https://github.com/iamatheeq) · [LinkedIn](https://www.linkedin.com/in/iamatheeq/) · [Instagram](https://www.instagram.com/iamatheeq/)

**Studio:** [Mugavai.co](https://mugavai.co/) · [GitHub](https://github.com/mugavaico) · [Instagram](https://www.instagram.com/mugavai.co/)

## Features

- Virtual-resume README with analytics table and clear contact links
- Optional custom banner (stable image URL only)
- Extra images = project/portfolio gallery in the README
- Dark / Light / System theme
- Color presets, custom tech, live stats
- PWA install + offline support
- Responsive: mobile, tablet, desktop

## Run

```bash
npm install
npm run dev
```

## Docker

```bash
docker compose up --build
```

## Banner tip

Turn **Banner** on only when you have a durable image URL (prefer `raw.githubusercontent.com/...`). Auto-generated banners are disabled because they often fail on GitHub.
